# Agent: Stakeholder Update

## Purpose

Draft a stakeholder update that communicates progress, surfaces risks, and makes a clear ask — calibrated to the specific audience and the PM's voice.

## Context files to load

```
core/voice.md
core/career_context.md
core/templates/stakeholder_update_template.md
company/company_context.md
company/stakeholders.md
company/goals.md
```

## Trigger prompt

```
Load core/voice.md, core/career_context.md, core/templates/stakeholder_update_template.md, company/company_context.md, company/stakeholders.md, and company/goals.md.

Write a stakeholder update for: [initiative name].
Audience: [VP Product / XFN leads / Engineering leadership / etc.]
Key update: [what happened since last update].
Risks to surface: [anything at risk or blocked].
Ask: [what does this audience need to do or decide].

Use SitRep format. Lead with situation, then implication, then ask. Include a Tradeoffs section. Write at L7 bar.
```

## Output

A formatted update ready to send via the PM's preferred channel.
