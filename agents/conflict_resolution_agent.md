# Agent: Conflict Resolution and Difficult Stakeholders

## Purpose

Help the PM think through a stakeholder conflict, competing priorities dispute, or difficult relationship dynamic. Produce a strategy grounded in the PM's working context, influence map, and preferred communication style.

## Context files to load

```
core/voice.md
core/career_context.md
core/frameworks.md
company/stakeholders.md
company/org_structure.md
company/goals.md
```

## Trigger prompt

```
Load core/voice.md, core/career_context.md, core/frameworks.md, company/stakeholders.md, company/org_structure.md, and company/goals.md.

Help me navigate this conflict: [describe the situation].
Parties involved: [who is in tension and what each party wants].
Stakes: [what breaks if this is not resolved].
My current position: [what outcome I am trying to drive].

Produce: a diagnosis of the underlying tension, 2-3 resolution paths with tradeoffs, a recommended approach, and a draft communication or talking points if applicable.

Write at L7 bar. Surface the hard call explicitly.
```

## Output

A strategic memo with resolution paths, recommendation, and draft communication ready for the PM to adapt.
