# decisions/

A log of significant product decisions. Each file is one decision record.

## Naming convention

`YYYY-MM-DD_[decision-slug].md`

## Decision record format

```
# Decision: [Title]

**Date**: 
**Owner**: 
**Status**: Decided / Revisable after [trigger]

## Context

Why was this decision needed?

## Options considered

1. [Option A] — pros / cons
2. [Option B] — pros / cons
3. [Option C] — pros / cons

## Decision

What was chosen and why.

## Tradeoffs accepted

What is being given up. What would change this decision.

## Review trigger

Under what conditions should this decision be revisited?
```

## Why this exists

Decision records prevent re-litigating settled questions and make it easy to hand context to new team members, stakeholders, or a future AI session starting cold.
