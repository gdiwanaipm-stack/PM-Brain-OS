# research/

Curated snapshots of user research relevant to current initiatives. Each file is a self-contained synthesis — not raw transcripts, but digested insight.

## Naming convention

`YYYY-MM_[study-name].md`

## What belongs here

- User interview synthesis (use the research synthesis template)
- Usability test findings
- Survey result summaries
- Relevant data analysis outputs
- Competitive UX teardowns

## What does not belong here

Raw transcripts, unprocessed survey data, or notes without a synthesis pass. This library is a knowledge layer, not a dump.

## Freshness

Each file should include a date. Research older than 12 months should be reviewed for continued relevance before being used in a prompt.
